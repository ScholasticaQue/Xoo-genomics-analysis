# Xoo-genomics-analysis
## Project: Xoo Genomics Analysis

### Objective
Compare 3 new Xoo strains with published strains using SNP-based phylogeny

### Workflow
1. BAM → SNP calling (Snippy)
2. Core SNP alignment
3. Phylogenetic tree (IQ-TREE)

### Data
Raw data stored locally (not included in repo)

### Scripts
- scripts/run_snippy.sh
